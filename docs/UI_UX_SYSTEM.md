# UI UX System

## Purpose

This document defines the visual and interaction language of Momenta.

The goal is:

* premium appearance
* calm experience
* consistent interactions
* long-term scalability
* Apple-grade quality

Every screen, widget, card, animation, notification, and setting must follow this system.

---

# Design Philosophy

Momenta is:

* calm
* elegant
* trustworthy
* minimal
* personal

Momenta is not:

* flashy
* gamified
* noisy
* corporate
* overloaded

The product should feel like:

"A quiet assistant that helps you remember what matters."

---

# Visual Direction

Target quality level:

Apple-grade.

Design priorities:

1. clarity
2. readability
3. hierarchy
4. calmness
5. consistency

before decoration.

---

# Core Visual Principles

## Simplicity

Every screen should focus on one primary action.

Avoid:

* excessive buttons
* crowded layouts
* visual clutter

---

## Breathing Space

Whitespace is a feature.

Layouts should feel relaxed.

Never compress content unnecessarily.

---

## Information Hierarchy

Users should immediately understand:

* what is important
* what is upcoming
* what requires attention

without effort.

---

## Calm Attention

Warnings should attract attention without creating anxiety.

Example:

Vehicle inspection in 5 days

instead of

URGENT WARNING !!!

---

# Design Tokens

All UI values come from tokens.

Never hardcode:

* colors
* font sizes
* spacing
* radii
* shadows

---

# Color Philosophy

Colors communicate meaning.

Not decoration.

Examples:

Family

Health

Vehicle

Finance

Home

Pet

Self

Premium

Warning

Success

Muted

All category colors come from Semantic Color Registry.

---

# Typography

Typography must prioritize readability.

Hierarchy:

Display

Heading

Title

Body

Caption

Micro

---

Rules:

Avoid excessive font sizes.

Avoid tiny text.

Readable widgets are mandatory.

---

# Cards

Cards are the primary surface.

Card principles:

* soft corners
* clean hierarchy
* sufficient spacing
* clear tap targets

Cards should feel:

lightweight

not heavy

---

# Buttons

Primary

Secondary

Tertiary

Destructive

Button styles must be globally defined.

---

# Icons

Icon language must be consistent.

Rules:

* simple
* recognizable
* category-aware
* accessible

Avoid decorative icon overload.

---

# Empty States

Empty states are product moments.

Examples:

No moments yet

Today feels quiet

Nothing upcoming

Empty states should feel intentional.

Never display:

blank screens

---

# Loading States

Loading should feel smooth.

Use:

* skeletons
* placeholders
* subtle transitions

Avoid:

* spinners everywhere

---

# Error States

Error states must:

* explain
* reassure
* offer recovery

Avoid technical language.

---

# Motion Philosophy

Motion supports understanding.

Motion does not exist for decoration.

---

Use motion for:

* transitions
* hierarchy
* confirmation
* orientation

Avoid:

* excessive movement
* distracting effects

---

# Haptic Philosophy

Haptics should feel intentional.

Examples:

Moment saved

Reminder enabled

Premium unlocked

Archive completed

Avoid haptic spam.

---

# Home Screen Design

Home should answer:

What matters today?

within seconds.

Sections:

Upcoming

Overdue

Recent

Insights

Quick Add

---

Home is not a dashboard.

Home is a life timeline surface.

---

# Moment Detail Design

Moment detail should feel focused.

Show:

* title
* category
* elapsed time
* countdown
* reminders

Hide unnecessary complexity.

---

# Reminder Design

Reminder configuration must be simple.

Users should not need technical scheduling knowledge.

---

# Widget Design Philosophy

Widgets are a primary product surface.

Widgets must be:

* glanceable
* readable
* useful
* calm

---

Widget sizes:

Small

Medium

Large

---

Widget modes:

Elapsed

Countdown

Minimal

Compact

---

# Premium Experience

Premium should feel valuable.

Not manipulative.

Avoid:

* dark patterns
* fake urgency
* aggressive upsells

---

# Settings Design

Settings should feel organized.

Sections:

Appearance

Language

Notifications

Widgets

Privacy

Data

Premium

About

---

# Accessibility Design

Every screen must support:

* VoiceOver
* Dynamic Type
* Reduce Motion
* contrast requirements

Accessibility is part of design.

---

# Notification Design

Notifications should feel helpful.

Not demanding.

Good:

Vehicle inspection in 7 days.

Bad:

You forgot again!

---

# Insight Design

Insights should feel supportive.

Never judgmental.

Good:

Your Family category has been quiet lately.

Bad:

You are neglecting your family.

---

# App Store Visual Standard

All screenshots must follow:

* same spacing language
* same typography language
* same color language
* same card language

No marketing chaos.

---

# Future Design Rule

Every new UI component must answer:

Does this increase clarity?

If not, it should not exist.

---

# Final UX Rule

The user should feel:

calm

organized

aware

in control

Momenta succeeds when users think:

"I don't have to remember everything anymore."
