# MVP Definition

## Purpose

This document defines the exact scope of the first public release of Momenta.

The goal is:

* avoid scope creep
* reach App Store faster
* validate product-market fit
* collect real user feedback

This document defines what is included and what is excluded.

---

# MVP Goal

The first release must prove one thing:

Users find value in remembering important life moments through a calm, widget-first experience.

Nothing else is required.

---

# MVP Success Criteria

A user should be able to:

1. install Momenta
2. create a moment
3. receive reminders
4. see time passing
5. use a widget
6. return to the app repeatedly

If these goals work, MVP succeeds.

---

# MVP Product Promise

Remember What Matters.

The MVP must focus entirely on this promise.

# MVP Widget Rules

MVP widgets must:

* be readable
* update correctly
* open the correct moment
* respect privacy settings

Complexity is not required.

Reliability is required.

---

# MVP Release Question

Before release ask:

Can a user successfully remember something important using Momenta every day?

If the answer is yes,

MVP is ready.

If the answer is no,

MVP is not ready.

---

# Final Rule

Do not expand MVP.

Ship.

Learn.

Improve.

The first release is not the final product.

The first release validates the product.
